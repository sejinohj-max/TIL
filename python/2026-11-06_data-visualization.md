## 📚 오늘 배운 것: 데이터 시각화

👉 정리 아티팩트: [데이터 시각화 노트](https://sejinohj-max.github.io/TIL/artifacts/python/data-visualization.html)

- EDA는 CRISP-DM의 앞 세 단계(비즈니스 이해 → 데이터 이해 → 데이터 준비)에 걸쳐 있고, 그래프와 수치 통계량 두 방향으로 데이터를 확인하는 과정
- 변수 종류(수치형/범주형)와 전달 목적(추이·비교·분포·관계·비율)에 따라 차트를 고름
- matplotlib으로 선형·막대·히스토그램·산점도·원형·박스플롯, seaborn으로 hue·pairplot·countplot·barplot·heatmap 실습
- 사분위수와 IQR로 박스플롯의 수염과 이상치 기준(Q1−1.5·IQR, Q3+1.5·IQR)을 직접 계산
- 워드클라우드, folium 지도 시각화 맛보기

**인상 깊었던 것** — '시각화의 함정'. 같은 임금 데이터인데 세로축을 실제 금액/로그/첫해=100 중 무엇으로 잡느냐에 따라 "상사가 더 많이 오른다"와 "근로자가 더 빨리 오른다"가 둘 다 맞는 말이 된다. 그래프는 사실을 보여주는 도구이면서 동시에 해석을 고르는 도구라는 점. 히스토그램 bin 크기만 바꿔도 분포 모양이 달라 보이는 것도 같은 맥락.

## 🧭 커리어 브랜딩: 나를 탐색하기

오늘은 수업 외에 내 커리어 강점을 정리해보는 시간이 있었다.

- **내 브랜드 한 문장**: 소통·기획력·학습력을 바탕으로, 기술과 정책, 한국과 전세계 사이의 언어를 옮기며, 데이터를 현장의 문제 해결로 연결하는 사람
- **KANT에서 얻고 싶은 것**: 사람의 눈과 언어 감각에 의존해온 리서치를 SQL·파이썬·데이터 플랫폼으로 설계하고 검증하는 법
- **해결하고 싶은 문제**: 여러 언어와 출처에 흩어진 정보 때문에 리스크를 늦게 발견하는 문제 — 외교·안보·컴플라이언스 실무자가 더 빠르고 근거 있게 판단하도록 돕기
- **3년 뒤**: Embedded Consultant / Deployment Strategist처럼 고객 현장에서 문제를 정의하고, 데이터로 해법을 설계하고, 기술팀과 고객 사이를 잇는 사람
- **연관검색어로 남기고 싶은 키워드**: 데이터 기반 리스크 분석 · Deployment Strategist · 국제안보 × AI
