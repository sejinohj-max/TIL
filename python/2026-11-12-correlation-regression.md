## 오늘 배운 것

- **LLM과 클래스**: 분류 모델은 각 클래스에 속할 확률 P(클래스 | 입력)를 내보낸다. LLM은 다음 단어를 고르는 다중 분류 모델이고, 확률분포에서 매번 샘플링해서 같은 질문에도 답이 달라진다.
- **공분산 → 상관계수**: 키를 m에서 cm로 바꾸면 공분산이 100배가 되지만 관계는 그대로. 표준편차로 나눈 상관계수 r(−1 ~ 1)은 단위에 상관없다. 상관은 순서가 없고 인과도 아니다.
- **이상치와 시각화**: 이상치 하나로 r의 부호가 뒤집힐 수 있다. 앤스콤 콰르텟처럼 숫자가 같아도 모양이 다를 수 있으니 플로팅하고 숫자로도 본다. 순위 기반 스피어만, 쌍별 순서를 세는 켄달 τ = (일치 − 불일치) / 전체 쌍.
- **회귀계수와 결정계수**: 상관은 관계를, 회귀는 크기("공부를 얼마나")를 보여 준다. R² = 1 − (모델 오차 / 평균으로 찍었을 때 오차). 정책 분석은 R² 크기보다 회귀계수의 방향·크기·유의성을 본다.
- **비선형 모델**: 선형회귀는 1차방정식. 행은 방정식 수, 열(축)은 변수 수, 차수는 제곱 횟수. 축을 늘리면(x²) 직선으로 나눌 수 있다. 비선형 변환 후 선형 모델링.
- **활성화 함수**: 신경망이 비선형인 이유는 f. 시그모이드(0 ~ 1), tanh(−1 ~ 1), ReLU(음수 → 0), Leaky ReLU, 항등함수, 각각 장단점이 있다. 시그모이드 0.5 이상이면 생존.
- **의사결정나무와 설득**: 수업 데이터에서 성능 1위. 모델 적용 후에는 파일럿으로 예측과 실제를 비교해서 비즈니스적으로 설득한다.

## 돌아보기

- 어제 Z-score, 변동계수, 스케일링에 이어 오늘 상관계수까지, 결국 전부 "표준편차로 나눠서 단위를 지운다"는 같은 아이디어였다. 단위 이야기가 계속 나오는 이유를 알 것 같다.
- 회귀분석을 공공정책 맥락에서 정리했다. 정책은 독립변수를 바꿔서 실제로 개선하는 게 목적이라 R² 숫자보다 회귀계수와 유의성이 중요하다. (회귀 결과를 정책에 되돌려 반영하는 건 "환류")
- 행, 열, 차수를 헷갈렸다가 정리했다. 행 = 방정식 개수, 열 = 변수 개수, 차수 = 몇 제곱.
- ReLU는 웃기는 비선형 함수다. 꺾임이 딱 하나인데도 비선형이다.
- 모델을 만들고 끝이 아니라, 파일럿으로 예측과 실제를 비교해서 "이걸 쓸 수 있겠구나"를 보여 주는 단계까지가 일이라는 점이 기획 쪽 관점에서 인상 깊었다.
