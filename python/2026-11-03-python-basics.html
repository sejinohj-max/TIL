f-string과 str(), 왜 결과가 같을까?

숫자를 문장 안에 넣으려면 먼저 글자로 바꿔야 해요. str(변수)는 그 변환을 직접 하는 거고, f"...{변수}..."는 중괄호 자리에서 파이썬이 알아서 같은 변환을 해줘요. 글자로 바꾸는 규칙(값이 자기를 글자로 보여주는 방법)이 하나라서, 결과도 같아요.

값을 골라 두 길을 비교
str() + 붙이기
→str( )→→"합격자 수: " + ▢ + "명"
f-string
→{ } 자리에서 자동 변환→→f"합격자 수: {▢}명"
한 줄 원리
f"합격자 수: {n}명"="합격자 수: " + str(n) + "명"

f-string은 사실 위 오른쪽 코드를 짧게 쓰는 방법이에요. { } 안의 값을 글자로 바꾸고(str이 하는 일), 앞뒤 글자와 이어 붙여요(+가 하는 일). 두 단계를 한 번에 해주는 거예요.

str(변수) + 붙이기f-string
변환내가 직접 str()로 감쌌야 함{ } 안에 넣기만 하면 자동
빼먹으면"수: " + 3 → TypeError에러 없음
계산 넣기str(5 * n){5 * n} (구구단 슬라이드)
자릿수 맞추기따로 round() 등 필요{x:.6f} 소수점 6자리 (노트북 시간 출력)
추천값 하나만 글자로 바꿀 때문장 안에 값을 끼울 때 (거의 항상)
자릿수 서식 맛보기 (f-string만 가능)
0.12109947204589844

콜론 뒤 .6f = "소수점 아래 6자리까지, 실수(f)로". 숫자 값은 그대로고 보여주는 모양만 바뀌어요.

if–elif vs 여러 if, 뭐가 달라?

둘 다 조건을 위에서 아래로 읽어요. 차이는 참을 만난 다음에 있어요. if–elif는 참 하나를 찾으면 거기서 내리고, 여러 if는 참이든 거짓이든 끝까지 하나하나 다 검사해요.

if – elif 한 세트
score = 95 if score >= 90: print("A") elif score >= 80: print("B")
  1. 참 90 이상? 맞아 → A 출력
  2. 패스 80 이상? 이미 답 찾았으니 안 봄
A

엘리베이터예요. 원하는 층(처음 참)에 도착하면 내리고, 위층은 안 가요.

if + if 따로따로 두 세트
score = 95 if score >= 90: print("A") if score >= 80: print("B")
  1. 참 90 이상? 맞아 → A 출력
  2. 참 80 이상? 이것도 맞아 → B 출력
A B

체크리스트예요. 항목마다 따로 확인해서 해당하는 건 전부 실행해요.

함정: 학점을 여러 if로 짜면?
score = 95 if score >= 90: grade = "A" if score >= 80: grade = "B" if score >= 70: grade = "C" if score >= 60: grade = "D" print(grade) # D (?!)
grade = "A"덮어씀
grade = "B"덮어씀
grade = "C"덮어씀
grade = "D"최종!

95점은 네 조건 모두 참이라 grade에 A→B→C→D가 차례로 들어가요. 마지막 값만 남아서 95점이 D가 돼요. 그래서 학점은 elif로 써야 해요.

if – elif – elseif 여러 개
검사 방식앞 조건이 거짓일 때만 다음 조건 검사모든 조건을 각각 검사
실행되는 블록딱 하나 (아무것도 참이 아니면 else)참인 것 전부 (0개일 수도)
조건 순서매우 중요 (큰 기준부터)결과가 바뀌는 경우가 적음
이럴 때 써요학점, 요금 구간처럼 하나만 골라야 할 때쿠폰·알림처럼 여러 개가 동시에 해당될 수 있을 때
