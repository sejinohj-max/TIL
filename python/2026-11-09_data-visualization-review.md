👉 정리 아티팩트: [데이터 시각화 노트](https://sejinohj-max.github.io/TIL/artifacts/python/data-visualization.html?v=1109)

지난 금요일(11/06)에 만든 데이터 시각화 아티팩트를 **직접 눌러 보는 그래프 위주로 다시 만들고**, 수업 중 생긴 질문을 하나씩 풀면서 내용을 계속 보탰다.

- **1.03 Matplotlib 노트북 실습**: GDP 선 그래프, actual vs predicted, xlim·ylim, annotate, 막대·원형·박스플롯, Counter 히스토그램, 이미지 처리(흑백·회전·블러·밝기)까지 노트북 코드를 그대로 그려 봄
- **도화지(current figure) 규칙**: `plt.show()` 뒤에 `savefig()`를 부르면 빈 그림이 저장된다. `close()`, `clf()`, `figure()`, 셀 나누기도 같은 함정이 있다. 안전한 순서는 figure → plot → 꾸미기 → savefig → show
- **축을 고른다는 것**: 값(원래 vs 환산), 눈금(일반 vs 로그), 시작점(0 vs 확대) 세 가지를 정하는 일이다. 같은 임금 데이터가 조합마다 다른 결론을 말한다
- **도수분포표**: 계급·도수·상대도수·누적도수. 히스토그램은 이 표를 그림으로 옮긴 것
- **4분위수**: 줄 세우고 네 토막으로 자르는 세 지점. median = Q2 = describe()의 50%. 손 계산과 np.percentile은 값이 조금 다르고, 데이터가 많아질수록 차이가 사라진다
- **IQR × 1.5 울타리**: Q1=21, Q3=35면 IQR 14, 울타리 0~56, 그 밖의 값이 이상치. 공식에 Q2는 안 들어간다
- **pivot / pivot_table**: index = 세로 이름표, columns = 가로 이름표, values = 칸에 채울 숫자. pivot_table은 묶고 계산하고 펼치기까지 한 번에
- **distplot 은퇴 이유**: 한 함수가 너무 많은 일을 했고, hue가 없었고, y축 기본값이 밀도라 헷갈렸다 → `histplot(kde=True)`
- **barplot의 검은 선 = 95% 신뢰구간**: 평균이 표본에 따라 흔들리는 폭. 값이 들쭉날쭉하고 사람 수가 적을수록 길어진다
- 이 내용을 다섯 가지 유형(차트 고르기·OX·코드 읽기·계산·그래프 보고)의 **복습 퀴즈 44문제**로 묶음

## 🗣 튜터님 말씀 메모

- **"똘똘한 변수/이상치는 모델링까지 안고 가야 한다"**: 울타리 밖이라고 무조건 지우지 않는다. 입력 실수는 지우지만, 진짜 값이고 예측에 중요한 정보(사기 거래, 1등석 운임 같은)는 남긴다
- **"뉴럴 네트워크는 100% 맞히게 만들 수 있지만 그게 정답은 아니다"**: 학습 데이터를 통째로 외운 과적합 모델은 실험실 밖의 난잡한 데이터에서 무너진다. 중요한 건 처음 보는 데이터에서 얼마나 맞히느냐(일반화)

## 💭 돌아보기

- 오늘은 "헷갈리는 걸 그냥 넘기지 않는 날"이었다. median과 50%와 IQR, 손 계산과 기계 계산, 개수와 밀도처럼 비슷해 보이는 개념을 하나씩 짚어 보니, 대부분은 **같은 질문에 다른 기준으로 답한 것**이었다. 어떤 기준을 쓰는지 밝히는 게 분석하는 사람의 몫이라는 걸 다시 느꼈다.
- 축 조립기를 만들면서, 시각화의 함정은 그리는 사람의 의도만의 문제가 아니라 **읽는 사람이 축을 안 보는 습관**에서도 생긴다는 걸 알았다. 나중에 프로젝트에서 결과를 보고할 때는 단위, 눈금, 시작점을 먼저 말하는 습관을 들이고 싶다.
- 튜터님의 두 말씀(똘똘한 이상치, 과적합)은 결국 같은 이야기 같다. 데이터의 잡음과 신호를 구분하는 것. 이상치를 지울지 남길지, 모델을 얼마나 세밀하게 맞출지 모두 "이게 현실에서도 반복될 패턴인가?"를 묻는 일이다.
- 노트북 실습에서 `show()` 뒤 `savefig()` 버그를 발견한 게 재미있었다. 출력에 찍힌 `with 0 Axes` 한 줄이 단서였다. 코드를 돌리기만 하지 않고 출력을 읽는 습관이 중요하다.
