# TIL 2026-10-27 | 통계 기초에서 머신러닝·딥러닝 입문까지

## 1. 가설검정과 p값
- 귀무가설(차이 없음)을 기본값으로 두고, 데이터가 충분히 강할 때만 기각한다 (무죄추정과 같은 구조)
- p값: 귀무가설이 맞다고 할 때 지금만큼 극단적인 결과가 나올 확률. 유의수준 α(보통 5%)보다 작으면 유의하다고 본다
- 95% 신뢰수준 = 1 − α. 95라는 숫자는 자연법칙이 아니라 관례
- 통계는 치트키가 아니라 보조 수단 → "유의하다"에서 멈추지 말고 **효과 크기**와 실무적 의미를 설명할 것

## 2. 분산과 표준편차
- 편차 = 값 − 평균 → 합하면 항상 0 → 제곱해서 부호 제거 → 평균을 내면 분산 → 루트를 씌우면 표준편차(원래 단위로 복귀)
- [2, 4, 6]: 평균 4 / 편차 −2, 0, 2 / 편차² 4, 0, 4
  - 모집단: 분산 8/3 ≈ 2.67, 표준편차 ≈ 1.63
  - 표본: 분산 8/2 = 4, 표준편차 = 2
- 평균은 항상 ÷n, **분산만** 표본일 때 ÷(n−1) (pandas 기본 n−1, numpy 기본 n)
- 분산의 단위는 cm² 같은 제곱 단위라 해석이 어렵다 → 표준편차가 보기 편함
- 최빈값의 '빈'은 頻(빈도)

## 3. 회귀
- SST = Σ(y − ȳ)², SSR = Σ(ŷ − ȳ)², SSE = Σ(y − ŷ)², R² = 1 − SSE/SST
- 베이스라인 = 모두 평균으로 찍기(오차 = SST) → 모델의 SSE는 이보다 작아야 의미가 있다
- ŷ(와이햇) = 모델의 예측값 = 근사치
- fit = 오차 제곱합이 가장 작은 선을 찾는 것(최소제곱법) = 모델 학습
- 모든 변수를 수치화할 수 없으므로 현실에서 SSE = 0은 불가능
- '회귀'라는 이름은 골턴의 "평균으로의 회귀"에서 나옴 (우생학과 얽힌 역사가 있음)

## 4. 상관 vs 인과
- GPT는 다음 토큰을 통계적 패턴으로 예측한다 → 상관 기반
- 영국 고양이 수와 한국 경제성장률: 상관만으로 예측은 해볼 수 있지만 언제 깨질지 모른다
- 기준은 목적: 관찰해서 **예측**하려면 상관으로 충분할 수 있고, **개입**해서 결과를 바꾸려면 인과가 필요하다 (A/B 테스트)

## 5. 분류와 베이스라인
- 회귀는 숫자 하나, 분류는 클래스(범주) 중 하나를 예측
- 이진분류에서 7:3 정도의 불균형은 보통 그대로 진행
- 베이스라인: 균형 데이터면 찍기 50%, 7:3이면 다수 클래스만 찍어도 정확도 70% → 이걸 넘어야 최소 허들
- 허들을 넘었다고 쓸 만한 모델이라는 뜻은 아님
- 모델마다 장단점이 있다. 초등 산수를 교수에게 맡기지 않듯 문제에 맞는 모델을 고를 것

## 6. 지표
- 지표(index)는 원래 없던 것을 누군가 정의해서 만든 것 → 정의와 구성부터 확인할 것
- 주요 지표 외에 보조 지표도 함께 본다

## 7. 딥러닝 기초
- 노드: 입력 × 가중치를 더하고(+편향) 활성화 함수를 거쳐 출력
- 입력층 → 은닉층(여러 겹 쌓으면 딥러닝) → 출력층
- 출력층을 보면 모델 종류를 알 수 있다: 숫자 1개(회귀) / 클래스별 확률(분류)
- 텍스트도 이미지처럼 숫자로 바꿔서 처리한다 (토큰 → 임베딩)
- 학습: 데이터(x, y)는 고정, 가중치(w, b)만 수정. 데이터를 고치면 조작
- 역전파 + 경사하강법: 오차를 거꾸로 추적해 각 가중치의 기울기(미분)를 구하고, 오차가 줄어드는 방향으로 수정
- 데이터 하나마다가 아니라 배치 단위로 오차를 평균 내서 수정
- 손실함수: MSE(극단값에 민감), MAE(덜 민감), RMSE(원래 단위로 해석 가능)
- GPT의 파라미터 수천억 개 = 조정된 가중치 수천억 개
- 트랜스포머(2017) 이후 대부분의 LLM이 이 구조를 기반으로 함
- 모델을 공개했다 = 구조와 파라미터를 공개했다 → 파이썬으로 내려받아 실행할 수 있다

## 8. 과제: 엑셀 함수 솔루션 A/B
엑셀 함수를 제대로 이해해야 파이썬과 SQL도 이해된다. 하려는 일은 같고 도구만 바뀐다.

| 하려는 일 | 엑셀 | SQL | pandas |
|---|---|---|---|
| 조건으로 거르기 | 필터 / FILTER | WHERE | `df[df["col"] > 10]` |
| 조건에 따라 값 정하기 | IF | CASE WHEN | `np.where()` |
| 그룹별 합계 | SUMIF(S) | GROUP BY + SUM | `groupby().sum()` |
| 그룹별 개수 | COUNTIF(S) | GROUP BY + COUNT | `groupby().size()` |
| 다른 표에서 값 찾아오기 | VLOOKUP / XLOOKUP | JOIN | `merge()` |
| 요약표 만들기 | 피벗 테이블 | GROUP BY | `pivot_table()` |

## 💡 느낀 점
엑셀 함수를 제대로 이해하는 게 파이썬과 SQL의 기초가 된다. 통계도 마찬가지로 "유의하다"는 결론 하나보다, 그 숫자가 어떻게 만들어졌고 실무에서 무슨 의미인지를 설명할 수 있어야 한다.
