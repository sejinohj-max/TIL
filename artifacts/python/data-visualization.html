01EDA와 CRISP-DM

EDA(탐색적 데이터 분석)는 요약·시각화·통계로 데이터를 들여다보면서 숨은 패턴과 관계, 품질 문제를 찾는 과정이다. CRISP-DM의 6단계 중 앞의 세 단계(Business Understanding → Data Understanding → Data Preparation)에 걸쳐 있다.

단계EDA가 하는 일
Business Understanding목표·성공지표 정의, KPI가 데이터로 도달 가능한지 검토, 타당성(feasibility) 확인
Data Understanding변수의 의미·단위·범위 파악, 단변량/다변량 분포와 관계 확인, 결측·이상치·오류·중복 발견
Data Preparation정제, 파생변수 생성, 병합, 포맷 정리

EDA의 두 도구는 그래프(히스토그램, 산점도, 박스플롯 …)와 수치 통계량(min·max·mean·std·사분위수·p-value …)이다. 같은 질문을 이미지와 숫자 두 방향에서 확인한다.

04시각화의 함정

같은 데이터라도 축을 어떻게 잡느냐에 따라 결론이 달라 보인다.

세로축읽히는 결론
실제 임금, 일반 눈금상사 임금이 훨씬 높고 격차도 커진다
실제 임금, 로그 눈금근로자 임금이 상대적으로 더 빨리 오른다
첫해 = 100으로 환산근로자의 증가율이 훨씬 높다
  • 막대그래프의 y축이 0에서 시작하지 않으면 작은 차이가 크게 보인다 (여론조사 그래프 예시).
  • 값 하나가 너무 커서 축을 끊을 때는 물결선으로 생략을 표시해야 오해가 없다.

05도수분포표와 히스토그램

수치 데이터를 겹치지 않는 구간(계급, bin)으로 나누고 구간마다 개수(도수)를 센다. 구간은 "이상 ~ 미만"으로 잡아 중복을 막고, 도수의 합은 데이터 개수와 같아야 한다. 히스토그램은 이 표를 그림으로 옮긴 것이다.

bin 크기를 바꾸면 모양이 달라진다. 너무 넓으면 특징이 뭉개지고, 너무 좁으면 노이즈가 많아진다. 아래에서 수업 예시 데이터(사용자별 서비스 이용 시간)로 직접 바꿔 보자.

경계값 60은 60~70 구간에 들어간다 (왼쪽 포함, 오른쪽 미포함).

히스토그램 vs 막대그래프

히스토그램은 연속형 수치 데이터의 분포라서 막대가 붙어 있고 x축이 숫자 구간이다. 막대그래프는 범주형 데이터 비교라서 막대가 떨어져 있고 순서를 바꿔도 된다.

06사분위수, IQR, 박스플롯

데이터를 크기순으로 늘어놓고 4등분한 지점이 Q1(25%), Q2(중앙값, 50%), Q3(75%)다. IQR = Q3 − Q1은 가운데 50%가 퍼진 폭이다. df.describe()의 25%·50%·75% 행이 바로 이 값이다.

FENCE

lower fence = max(min, Q1 − 1.5×IQR)
upper fence = min(max, Q3 + 1.5×IQR)

WHISKER · OUTLIER

수염 끝 = fence 안쪽에 있는 실제 데이터의 최솟값/최댓값. fence 밖의 점은 이상치로 따로 찍힌다.

수업 예시: Q1=21, Q3=35 → IQR=14 → 위쪽 한계 35+21=56, 아래쪽 21−21=0. 최댓값 80은 이상치.

계산 방식은 np.percentile 기본값(선형 보간)과 같다. 손으로 계산하는 교과서 방식(중앙값 기준으로 반씩 나누기)을 쓰면 Q1=8, Q3=21처럼 조금 다르게 나올 수 있다.

07seaborn

matplotlib 위에 만든 통계 시각화 라이브러리. DataFrame을 data=로 넘기고 컬럼 이름만 적으면 된다.

함수하는 일
histplot히스토그램 (bins=, kde=True로 밀도선 추가)
kdeplot밀도 곡선
boxplot박스플롯
distplot히스토그램 + 밀도 (수업 예제)

barplot범주별 평균 막대 + 오차막대

hue: 범주 한 차원 더하기

tips = sns.load_dataset("tips")
sns.scatterplot(x="total_bill", y="tip", hue="time", data=tips)  # sex, smoker, day 로도
tips["tip_rate"] = tips["tip"] / tips["total_bill"]                # 파생변수
sns.boxplot(x="time", y="tip_rate", data=tips)                    # 점심/저녁 비교

pivot → heatmap

temp1 = titanic.groupby(['Embarked', 'Pclass'], as_index=False)['PassengerId'].count()
temp2 = temp1.pivot(index='Embarked', columns='Pclass', values='PassengerId')
sns.heatmap(temp2, annot=True, fmt='d')   # fmt='d' 면 1.3e+02 대신 127로 표시
실습하다 막히면
· distplot은 최신 seaborn에서 지원 종료 예정이라 경고가 뜬다. sns.histplot(x, bins=16, kde=True, stat='density')로 대체.
· pandas 2.0부터 pivot('Embarked','Pclass','PassengerId')처럼 위치 인자로 쓰면 에러. index=, columns=, values=를 적어야 한다.
· 상관 히트맵은 sns.heatmap(df.corr(numeric_only=True), annot=True, cmap='coolwarm'). Date와 Month처럼 0.98이 나오는 쌍은 사실상 같은 정보다.

08워드클라우드와 folium

WORDCLOUD
