배열 vs 벡터

벡터는 수학 용어, 배열은 프로그래밍 용어. 1차원 배열 = 벡터를 컴퓨터에 담은 모양.

수학NumPy
스칼라 (숫자 하나)0차원
벡터 (한 줄)1차원
행렬 (표)2차원
텐서3차원 이상

"벡터화"라는 이름도 벡터처럼 같은 자리끼리 통째로 계산한다는 뜻.

눌러보기 · np.arange(start, stop, step)
  • stop은 미포함. arange(0, 10)은 9에서 멈춤 (0 이상 10 미만)
  • start 생략 → 0, step 생략 → 1
  • range는 정수만, 결과가 숫자를 미리 안 만드는 반복 객체 → for문 횟수용
SJ 필기생략된 값은 "응 거기서 만나". 이미 서로 아는 곳: 시작은 0, 간격은 1.

flatten(): 납작하게 펴기

눌러보기 · 펴기
  • 원본은 그대로, 펴진 새 배열을 돌려줌 → 변수에 담아 써요 (flat = arr.flatten())
  • 왜? 머신러닝 모델·신경망 입력층(FC 레이어)은 데이터 하나를 한 줄로 받아요. 8×8 손글씨 → 64칸
  • 펴고 나서 / 255로 0~1 스케일링 → 노드에 하나씩 입력

인덱싱: 한 칸 콕

차원 수만큼 번호, 쉼표 = 축 구분, 번호는 0부터.

눌러보기 · 2차원 [행, 열]
칸을 눌러보세요
눌러보기 · 3차원 [층, 행, 열]
칸을 눌러보세요

3차원은 아파트 주소처럼 동 → 층 → 호, 큰 단위부터. arr[1][2]도 되지만 arr[1, 2]가 표준.

연습문제 정답 (슬라이드 41쪽) 
x[2] = 99          # 3번째 값
y[1, 0] = 100      # 두 번째 행, 첫 번째 값
z[0, 1, 1] = 300   # 첫 블록, 두 번째 행, 두 번째 값

함정: 문제는 "첫 번째·두 번째", 코드는 0·1. 사람 번호 − 1 = 인덱스.

슬라이싱: 구간 자르기

[start:stop:step] · start 포함, stop 미포함, step 생략은 1.

절대 안 헷갈리는 판별법

쉼표로 나눈 칸마다 묻기: 콜론(:)이 있나?

없음 → 인덱싱그 칸 자체, 무조건 포함. 그 축은 결과에서 사라짐.
arr[:, 1] → 1번 열 포함
있음 → 슬라이싱콜론 앞(시작) 포함, 콜론 뒤(멈춤) 미포함.
arr[:, 1:3] → 1, 2번 열

한 줄 암기: 콜론 바로 뒤에 붙은 숫자만 빠진다.

실험실 1 · 김밥 썰기

슬라이싱 숫자는 조각이 아니라 칼자국 번호. x[1:4] = 1번~4번 칼자국 사이 조각. 4번 칼자국은 4번 조각 왼쪽이라 4번 조각은 안 와요.

[:-1] vs [::-1]: -1이 어느 칸에?

콜론 개수로 자리를 세요. 김밥에서 두 칩을 번갈아 눌러보면 바로 보여요.

코드시작멈춤간격결과 (x = [0..6])
x[:-1]비움-1비움[0 1 2 3 4 5] 마지막 빼기
x[::-1]비움비움-1[6 5 4 3 2 1 0] 거꾸로

간격이 음수 = 뒤로 걷기. 끝에서 출발해 처음까지 한 칸씩 → 전체가 뒤집혀요.

np.sort(scores)[::-1]   # 높은 점수부터 (np.sort엔 내림차순 옵션이 없어서)
sales[::-1]             # 오래된 순 → 최신순
"hello"[::-1]           # 'olleh' 문자열도 똑같이

음수 인덱스: 뒤에서 세기

x1020304050 앞에서01234 뒤에서-5-4-3-2-1

공식: 음수 + 길이. -1 + 5 = 4 → x[-1] = x[4] = 50. (-0은 0이라 뒤에서는 -1부터)

코드판정결과
x[-1]콜론 없음 → 포함50
x[:-1]-1이 콜론 뒤 → 빠짐[10 20 30 40]
x[-1:]-1이 콜론 앞 → 포함[50]
x[-2:]-n: = 끝에서 n개[40 50]

2차원: 쉼표 앞 = 행, 뒤 = 열

규칙은 그대로, 칸마다 따로 판정. 쉼표 없이 arr[1:3]은 행에만 적용.

코드 (arr = 1~16, 4×4)고르는 것shape
arr[1:, 1]1~3행의 1번 열 (뒤 1은 콜론 없음 → 포함)(3,)
arr[1:, :1]1~3행의 0번 열 (1이 콜론 뒤 → 빠짐)(3, 1)
arr[:, -1]마지막 열(4,)
arr[:, -2:]마지막 두 열 (-2 + 4 = 2번부터)(4, 2)
arr[-1, :-1]마지막 행에서 마지막 칸 빼고 → [13 14 15](3,)

숫자로 콕 집은 축은 사라져서 차원이 줄어요. arr[1:, 1]은 한 줄 [6 10 14], arr[1:, 1:2]는 세로 막대 [[6] [10] [14]].

실무 단골X = data[:, :-1] 특징(마지막 열 빼고) · y = data[:, -1] 정답(마지막 열)
실험실 2 · 바둑판 미션

2차원 = 김밥 두 번 썰기. 노란 띠(행)와 파란 띠(열)가 겹치는 칸만 남아요.

행 · 쉼표 앞
열 · 쉼표 뒤

빨간 점선 = 목표. 위·왼쪽 숫자 = 칼자국. (비움) = 처음부터 / 끝까지.

무한 퀴즈 · 주소 찾기
점수 0 / 0연속 0

이 코드가 고르는 칸을 전부 누르고 채점. 문제는 매번 새로 나와요.

대괄호 안에 무엇을 넣느냐

대괄호 안넘어가는 것뜻
arr[1]숫자첫 축에서 1번
arr[1:3]슬라이스첫 축에서 구간
arr[1, 2]튜플 (1, 2)축마다 주소 하나 → 값 하나
arr[[1, 2]]리스트한 축에서 여러 개 → 두 줄 (팬시 인덱싱)
arr[arr > 5]True/False 배열조건 맞는 칸만

쉼표가 있으면 튜플, 안에 대괄호를 또 쓰면 리스트. 딕셔너리는 IndexError (위치가 아니라 이름표 구조라서).

쉼표 규칙 더 깊이: 왜 arr[, -2:]는 에러인가 
arr[, -2:]    # SyntaxError
arr[:, -2:]   # OK  마지막 두 열 (4, 2)
arr[-2:]      # OK  마지막 두 행 (2, 4)  ← 전혀 다름
  • 쉼표 사이 빈칸 금지. "전부"는 :로 채움. : = "처음부터 끝까지 다"
  • 뒤쪽 축은 생략 가능 (arr[1:3] = arr[1:3, :]), 앞쪽은 :로 자리 채우기
  • 이건 파이썬 공통 규칙. [, 1], (1, , 2), print(, 1) 전부 에러, 맨 끝 쉼표만 허용 ([1, 2,] OK)
  • 그래서 arr[1,]은 튜플 (1,)이 되어 arr[1]과 같음. 아무도 안 쓰지만
  • 튜플엔 행·열 개념이 없어요. "n번째 값 = n번째 축"은 NumPy의 약속
고수 모드 · 직접 타이핑

슬라이드 47쪽 답: [0:2:1, 0:2:1] → [[0 1] [4 5]]. (표 마지막 14는 15의 오타)
