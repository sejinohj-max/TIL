통계(Statistics)는 데이터를 수집·분석·해석·표현하는 학문이고, 크게 둘로 나뉘어요.

AI 시대에도 통계가 필요한 이유는 간단해요. 머신러닝·딥러닝은 통계적 요약과 판단 위에서 범위를 넓힌 것이라, 서로 대체가 아니라 상호 보완이에요. 문제와 데이터에 맞는 방법을 고르는 게 핵심이에요.

01 · 튜터님 강조통계'값'과 시각화

통계값은 데이터를 숫자 하나로 요약한 거예요. 그림은 같은 정보를 모양으로 보여 줘요. 둘을 짝지어 두면 헷갈리지 않아요.

02 · 평균 → 빼기 → 제곱 → 평균 → 루트분산과 표준편차

슬라이드 연습 문제 [2, 4, 6]으로 한 단계씩 해 봐요.

STEP 1
평균
(2+4+6)/3 = 4
STEP 2
편차 (값−평균)
−2, 0, 2
합은 항상 0
STEP 3
편차 제곱
4, 0, 4
STEP 4
분산 = 제곱의 평균
8/3 ≈ 2.67
STEP 5
표준편차 = √분산
√2.67 ≈ 1.63

왜 제곱하나: 음수 × 음수 = 양수

편차를 그냥 더하면 0이 돼서 퍼짐을 알 수 없어요. 제곱하면 (−2)×(−2) = 4처럼 방향은 사라지고 "얼마나 떨어졌나"만 남아요. 부호가 같으면 양수, 다르면 음수예요.

왜 루트를 씌우나: 단위 되돌리기

데이터분산 단위표준편차 단위
키cm²cm
나이세²세
운임달러²달러

n으로 나눌까, n−1로 나눌까: 자유도

자유도는 자유롭게 움직일 수 있는 값의 개수예요. 평균 4를 쓰는 순간 편차 합이 0이라는 제약이 생겨서, 편차 −2와 0을 알면 마지막 값은 자동으로 2가 돼요. 값 3개 중 자유로운 건 2개, 즉 n − 1이에요.

표본 평균 x̄는 그 표본에 딱 맞춰 계산된 값이라 편차 제곱합이 실제보다 작게 나와요. 그래서 n−1로 나눠 보정해요. 이걸 불편추정량이라고 불러요.

코드ddof나누는 수setosa 꽃받침 길이 (50개)
np.std(data)0 (기본)n0.3489
np.std(data, ddof=1)1n − 1≈ 0.3525
series.std() (pandas)1 (기본)n − 1≈ 0.3525
한 줄 규칙 추정에 쓴 값 하나당 자유도가 하나씩 줄어요. ddof는 delta degrees of freedom의 약자예요. t-검정, 회귀, 카이제곱에서도 같은 원리로 다시 나와요.

03 · 그리스 = 모집단, 알파벳 = 표본앞으로 자주 만날 그리스 문자

그리스 문자는 모집단의 진짜 값(모수), 알파벳은 내가 뽑은 표본에서 계산한 값(통계량)이에요. 위에 ^(햇)이 붙으면 "추정값"이에요.

의미모집단표본
평균μx̄
표준편차σs
분산σ²s²
상관계수ρr
회귀계수βb, β̂
μ는 이데아, x̄는 동굴 벽의 그림자 μ는 분명히 존재하지만 직접 볼 수 없는 값이고, x̄는 우리가 관찰할 수 있는 근사값이에요. 표본을 다시 뽑으면 그림자(x̄)는 흔들리지만 실체(μ)는 그대로예요. 이데아와 다른 점은 μ가 현실에 실제로 있는 숫자라는 것뿐이에요. 그래서 x̄ ≈ μ, 같다가 아니라 추정해요.

오늘 공식을 기호로 읽으면 σ = √( Σ(xᵢ − μ)² / n ), 표본 버전은 s = √( Σ(xᵢ − x̄)² / (n − 1) )이에요.

04 · 종 모양 위의 눈금정규분포와 σ 1, 2, 3

정규분포는 평균을 중심으로 좌우 대칭인 종 모양 분포예요. σ 범위는 평균 ± k × 표준편차로 구해요.

68-95-99.7 규칙은 반올림한 어림값(more or less)이에요. 정확히는 68.27%, 95.45%, 99.73%이고, 정확히 95%를 감싸는 범위는 ±1.96σ예요.
범위평균 170, σ 5타이타닉 나이 (29.70, 14.53)
±1σ (68%)165 ~ 17515.17 ~ 44.23
±2σ (95%)160 ~ 1800.65 ~ 58.75
±3σ (99.7%)155 ~ 185−13.88 ~ 73.28

나이 3σ 하한이 음수로 나와요. 나이가 완벽한 정규분포가 아니라는 신호예요. 공식은 기계적이지만 해석은 분포 모양을 보고 해요.

age = df["age"].dropna()
mean, std = age.mean(), age.std()
for k in [1, 2, 3]:
    lo, hi = mean - k*std, mean + k*std
    ratio = age.between(lo, hi).mean() * 100   # 실제로 범위 안에 든 비율
    print(f"{k}σ: {lo:.2f} ~ {hi:.2f} → 실제 {ratio:.1f}%")
식스 시그마 ㅋㅋ 모토로라가 시작하고 GE가 유명하게 만든 품질 관리 슬로건이에요. 목표는 100만 개 중 3.4개 불량인데, 이론상 ±6σ 밖은 10억 개 중 약 2개예요. 공정 평균이 1.5σ쯤 흔들린다고 미리 감안해서 숫자가 달라요. σ가 3에서 6으로 두 배가 될 뿐인데 불량률은 1,000개 중 2.7개에서 100만 개 중 3.4개로 줄어요. 정규분포의 꼬리가 바깥으로 갈수록 급격히 얇아지기 때문이에요.

정규성 확인: 그림 + 숫자

방법보는 것코드

Q-Q plot점이 기준 직선 근처에 놓이나stats.probplot(data, dist="norm", plot=plt)
Shapiro-Wilk작은 표본에 정확, W는 1에 가까울수록 정규stats.shapiro(data)
D'Agostino K²왜도와 첨도를 합쳐 판단stats.normaltest(data)
Anderson-Darling꼬리를 더 민감하게stats.anderson(data)
Kolmogorov-Smirnov정규분포와의 차이, 큰 표본stats.kstest(...)

setosa 꽃받침 길이 결과는 검정통계량 0.9777, p-value 0.4595였어요. p > 0.05라서 정규분포 가정을 기각할 근거가 없다예요. "정규분포다"라고 증명한 건 아니고, 틀렸다는 증거가 없을 뿐이에요. p-value 0.4595는 "정규분포일 확률 45.95%"도 아니에요.

검정도 표본 크기에 휘둘려요 표본이 수만 개면 아주 조금만 달라도 기각되고, 수십 개 이하면 꽤 달라도 못 잡아요. 그래서 그래프로 모양을 보고, 검정으로 숫자를 확인하고, 둘을 같이 판단해요. pandas .kurt()는 정규분포를 0으로 맞춘 값이라 슬라이드의 k = 3 기준과 3만큼 차이 나요.

05 · 값에 의미를 주는 작업Z-score

z = (값 − 평균) / 표준편차

σ 범위 계산을 거꾸로 뒤집은 거예요. σ 범위는 "k배 떨어진 값은?"이고, Z-score는 "이 값은 몇 배 떨어졌나?"예요. 원래 단위를 떼어 내고 표준편차 몇 개만큼이라는 공통 단위로 바꿔서, 서로 다른 집단의 값을 비교할 수 있게 해요.

과목내 점수평균표준편차Z-score
수학807052.0
영어9085100.5

점수는 영어가 높지만, 반 안에서의 상대적 위치는 수학이 훨씬 좋아요.

같은 38세, 다른 의미

집단평균표준편차38세의 z의미
타이타닉 승객29.714.5+0.57평균보다 조금 많음 (하위 약 71.6%)
대학 신입생202+9.0극단적인 이상치
은퇴자 모임686−5.0극단적으로 젊음

단위 문제를 푸는 세 가지 도구

"표준편차 15"만 봐서는 큰지 작은지 알 수 없어요. 시험 점수에선 크고, 원 단위 연봉에선 사실상 0이에요.

비교하고 싶은 것도구식
다른 집단에 속한 값의 상대적 위치Z-score(x − 평균) / σ
단위가 다른 집단의 퍼짐 정도변동계수 CVσ / 평균 (키 2.9% vs 몸무게 15.4%)
모델에 넣기 전 변수 크기 맞추기스케일링표준화, Min-Max, Robust

Z-score로 백분위를 구할 땐 norm.cdf(z) * 100을 써요. z = −0.53이면 약 29.8%(하위 30%)예요. 단, 정규분포 전제가 있을 때만 정확해요.

06 · 평균 기준 vs 순서 기준이상치: IQR과 Z-score

구분Z-score 방법IQR 방법
기준 통계값평균, 표준편차중앙값, Q1, Q3
이상치 기준|z| > 3 (또는 2)Q1 − 1.5×IQR 미만, Q3 + 1.5×IQR 초과
전제정규분포에 가까울 때분포 모양 상관없음
이상치 영향크게 받음 (가리기 효과)거의 안 받음
짝꿍 그래프히스토그램박스플롯
잘 맞는 데이터키, 시험 점수운임, 연봉

IQR = Q3 − Q1은 가운데 50% 데이터가 퍼진 폭이에요. 정규분포에서 1.5×IQR 경계는 평균에서 약 2.7σ 지점이라, 데이터가 정규분포면 두 방법 결과가 비슷해요.

가리기 효과 이상치가 평균을 끌고 표준편차를 키우면, 기준선이 넓어져서 정작 이상치의 |z|가 작게 나와요. 운임처럼 치우친 데이터에서는 IQR이 더 많이 잡아요. 그래도 1등석 운임이 비싼 건 오류가 아니라 사실이라, 결과는 도메인 지식으로 한 번 더 판단해요.
q1, q3 = fare.quantile(0.25), fare.quantile(0.75)
iqr = q3 - q1
iqr_out = fare[(fare < q1 - 1.5*iqr) | (fare > q3 + 1.5*iqr)]
z = (fare - fare.mean()) / fare.std()
z_out = fare[z.abs() > 3]

07 · 표본평균은 결국 종 모양중심극한정리

원래 분포가 어떤 모양이든, 표본 크기가 충분히 크면 표본평균들의 분포가 정규분포에 가까워져요. 경험 법칙은 n ≥ 30이에요.

원래 분포필요한 표본 크기
이미 정규분포에 가까움10개 이하도 충분
약간 치우침30개 정도
심하게 치우침 (운임, 연봉)50 ~ 100개 이상
  • 정규분포가 되는 건 원래 데이터가 아니라 표본평균들이에요.
  • 표본평균들의 퍼짐은 표준오차 σ / √n이에요. n이 4배면 절반으로 줄어요.
  • 그래서 원래 데이터가 정규분포가 아니어도 평균에 대한 신뢰구간, t-검정을 할 수 있어요.

08 · 드디어확률

P(A) = A가 일어나는 경우의 수 / 모든 경우의 수

동전 2개: 모든 경우 4가지(앞앞, 앞뒤, 뒤앞, 뒤뒤), 같은 면 2가지라서 2/4 = 0.5. 경우의 수는 전체를 넘을 수 없으니 확률은 항상 0 ~ 1이에요. 주사위 확률분포는 1부터 6까지 각각 1/6이고, 모두 더하면 1이에요.

배달 시간 문제

질문계산답
가장 가능성 큰 시간대최대 확률30 ~ 40분 (40%)
30분 미만10% + 25%35%
40분 이상20% + 5%25%

평균 35분인 두 업체 중 중요한 약속이면 업체 A(대부분 30~40분). 업체 B는 10분 아니면 60분이라 지각 위험이 커요. 확률 파트에서도 결국 평균과 퍼짐을 같이 봐요.

야구 승률 0%의 진짜 뜻 중계 화면의 승리 확률은 과거 같은 상황(이닝, 점수 차, 아웃, 주자)에서 실제로 몇 번 이겼는지로 만든 경험적 확률이에요. 0%는 "불가능"이 아니라 "기록상 뒤집은 사례가 없었다"예요. 반올림으로 0%가 되는 경우도 많아요. 관찰되지 않음과 불가능은 달라요(블랙 스완). 과거 데이터는 동굴 벽의 그림자예요.

이산 vs 연속

구분값의 성격예
이산 확률분포하나씩 셀 수 있음주사위 눈, 구매 고객 수
연속 확률분포범위 안에서 연속적으로 잼키, 배달 시간

이산·연속은 값의 종류, 균등·이항·정규·포아송은 확률을 배분하는 방식이에요. 주사위 한 번은 이산 균등분포, 10번 던져 6이 나온 횟수는 이항분포예요.

10 · 큰 단위가 독차지한다스케일링과 모델

그래프는 숫자의 크기를 그려서, 단위가 크면 중요해 보이고 작으면 묻혀요. 나이(0~80)와 연봉(0~1억)을 한 그래프에 그리면 나이의 퍼짐은 바닥에 납작하게 사라져요. cm와 m가 섞인 키는 가짜 봉우리를 만들어요.

방법계산결과언제
표준화 StandardScaler(x − 평균) / σ평균 0, σ 1기본. Z-score와 같아요
정규화 MinMaxScaler(x − min) / (max − min)0 ~ 1범위를 딱 맞출 때. 이상치에 약함
로버스트 RobustScaler(x − 중앙값) / IQR중앙값 0 기준이상치가 많을 때
  • 표준화는 스케일링의 한 종류예요. 포함 관계예요.
  • 스케일링에서 "정규화"는 보통 Min-Max이고, 정규분포와는 관계없어요.
  • 세 방법 모두 눈금만 바꾸는 선형 변환이라 분포 모양은 그대로예요. 치우침을 펴려면 np.log1p 같은 변환이 필요해요.
  • 모델을 만들 땐 평균·σ를 학습 데이터로만 fit 해요. 테스트 데이터까지 쓰면 데이터 누수예요.

뉴런이 놀라는 이유

뉴런 입력은 z = w₁×나이 + w₂×연봉 + b. 가중치 0.01로 시작하면 나이는 0.35, 연봉은 500,000이 들어가요.

현상무슨 일
입력 쏠림출력을 연봉이 혼자 결정
활성화 포화sigmoid·tanh가 1에 붙어 기울기 ≈ 0, 학습 정지 (기울기 소실)
업데이트 불균형학습률을 크게 잡으면 연봉 가중치가 튕기고, 작게 잡으면 나이 가중치가 안 움직임

분류 모델의 오차: 교차 엔트로피

출력층 노드는 클래스 수만큼 있고, 소프트맥스로 각 클래스 확률(합 1)을 내보내요. 정답은 원-핫 인코딩으로 같은 모양으로 바꿔서 비교해요.

정답원-핫모델 예측손실 = −log(정답 확률)
setosa[1, 0, 0][0.9, 0.07, 0.03]0.11
setosa[1, 0, 0][0.7, 0.2, 0.1]0.36
setosa[1, 0, 0][0.1, 0.6, 0.3]2.30
  • 자신 있게 틀릴수록 손실이 급격히 커져요.
  • 2개 분류는 Binary Cross-Entropy(베르누이), 3개 이상은 Categorical Cross-Entropy(범주형).
  • 회귀의 MSE는 분산과 같은 구조(빼기 → 제곱 → 평균)이고 정규분포 오차를 가정해요. 가정한 분포가 오차 함수를 정해요.
  • 0, 1, 2로 번호를 붙이는 레이블 인코딩은 없는 순서·크기를 만들 수 있어서, 원-핫으로 모든 클래스를 동등하게 둬요.
