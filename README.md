## 1. DIKW
- 데이터 → (분석) → 정보 → (경험) → 지식 → (철학) → 지혜
- 예: "42.3m"(데이터) → "기준까지 2.7m, 상승 중"(정보) → "6시간 후 초과 예상"(지식) → "단계적 방류 + 경보"(지혜)

## 2. 데이터 리터러시 4역량
| 역량 | 핵심 질문 |
|---|---|
| 읽기 | 이 숫자의 기준·정의는? (예: 수료율 80%의 분모는?) |
| 분석 | 어떤 차이·패턴이 있나? |
| 활용 | 그래서 무엇을 할 것인가? |
| 소통 | 사실 / 해석·한계 / 제안을 구분해 전달 |

## 3. CRISP-DM
비즈니스 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 배포 (반복 구조)
- 평가 단계는 정확도가 아니라 **비즈니스 목표 달성 여부**를 본다

## 4. 데이터 분류
- 자료형: int / float / str / bool
- 변수 타입: 범주형(명목·서열), 수치형(이산·연속)
- 구조: 정형 / 반정형(JSON, 로그) / 비정형(텍스트, 이미지, 음성, 영상)
- 자료형을 나누는 이유: **효율 + 안정성** (트레이드오프)
  - 예: `0.1 + 0.2 == 0.3` → False (부동소수점 오차)
- 숫자처럼 보여도 범주형인 값이 있다 (우편번호, 등급)
- 시계열은 순서가 정보 → 섞어서 train/test 나누면 data leakage

## 5. 통계
- 평균은 극단값에 약하고, 중앙값은 극단값의 영향을 덜 받는다
- 분산 = 편차²의 평균, 표준편차 = √분산
  - 예: [2,4,6] → 분산 8/3 ≈ 2.67, 표준편차 ≈ 1.63
- SST = SSR + SSE, R² = 1 − SSE/SST
- 상관 ≠ 인과

## 6. 추론통계와 유의성
- 빅데이터여도 실무 데이터는 결국 **표본** → 크기보다 **대표성(편향)**이 중요
- 표본이 작으면 실제 차이도 유의하지 않게 나올 수 있다 (검정력 부족)
- 표본이 크면 작은 차이도 유의하게 나온다 → **통계적 유의 ≠ 비즈니스적 유의**, 효과 크기를 함께 봐야 한다

## 7. 통계의 함정
- **생존편향**: 귀환한 비행기의 총알 자국 → 자국이 없는 곳을 보강
- **평균의 함정**: 평균 37.3세인데 실제 고객은 20대 초반과 50대 초반에 몰려 있음 → 분포를 볼 것
- **앤스컴 콰르텟**: 통계량이 같아도 데이터 모양은 다르다 → 시각화 필수
- **심슨의 역설**: 집단별로는 B반이 높은데 합치면 A반이 높음 → 원인은 구성 비중 차이. 집단별 비율과 인원수를 같이 확인할 것

## 💡 느낀 점
효율과 안정성, 통계적 유의성과 비즈니스적 의미처럼 항상 트레이드오프와 맥락을 같이 봐야 한다.
