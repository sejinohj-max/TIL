# TIL · Today I Learned

데이터 사이언스 부트캠프(Data Science Lv1)를 들으며 배운 것과 느낀 점을 기록하는 저장소입니다.

## 이렇게 공부하고, 이렇게 기록합니다

**공부는 만들면서 합니다.**
수업 내용을 Claude와 함께 인터랙티브 학습 페이지(아티팩트)로 만들고, 직접 눌러보고 질문을 주고받으며 이해합니다. 코드 옆에 "사람 말 해석"을 붙이고, 퀴즈로 확인하는 식입니다.

**기록은 돌아보기 중심입니다.**
배운 내용은 핵심만 몇 줄로 요약하고 학습 페이지 링크를 남깁니다. 대신 TIL의 중심에는 수업과 프로젝트를 하며 **무엇이 헷갈렸고, 무엇을 느꼈고, 다음엔 어떻게 할지**를 직접 씁니다.

> AI는 학습 도구를 만들고 내용을 정리하는 데 씁니다.
> 회고는 제 말로 씁니다.

## 기록 형식

| 항목 | 내용 |
|---|---|
| 오늘 배운 것 | 한 줄 요약 |
| 핵심 개념 | 2~3개, 필요하면 짧은 코드 |
| 헷갈렸던 점 | 막혔던 부분과 해결 |
| 느낀 점 | 수업·프로젝트 회고 |
| 공부 자료 | 학습 페이지(아티팩트) 링크 |
