## 1. 좌표 위의 직선: y = ax + b
- a = 기울기 (x가 1 늘 때 y의 변화량), b = y절편 (x = 0일 때의 y값)
- 머신러닝의 `ŷ = w·x + b`와 같은 식. 기울기 → 가중치 w, 절편 → 편향 b
- 회귀선 찾기 = 데이터에 가장 잘 맞는 a, b 찾기 = 모델 학습

## 2. 차수: 1차, 2차, 3차
- 차수 = 식에서 x의 지수 중 가장 큰 값

| 차수 | 일반형 | 그래프 | 꺾이는 횟수 |
|---|---|---|---|
| 1차 | y = ax + b | 직선 | 0번 |
| 2차 | y = ax² + bx + c | 포물선 (a > 0이면 U자, a < 0이면 ∩자) | 최대 1번 |
| 3차 | y = ax³ + bx² + cx + d | S자 물결 | 최대 2번 |

- n차식은 최대 n−1번 꺾인다
- 차수를 높이면 데이터에 더 잘 맞지만, 너무 높이면 과적합
- 경사하강법의 오차 곡선 = U자 2차 곡선, 골짜기 = 최솟값

## 3. 지수와 지표
- 지표(indicator): 상태를 판단하는 모든 측정값 (실업률, 전환율)
- 지수(index): 기준 시점 = 100으로 놓은 상대값. 지표의 한 종류 (물가지수, 코스피)
- 지수(exponent): 거듭제곱에서 곱하는 횟수 (x³의 3). 차수는 이 지수 중 가장 큰 값

## 4. 파이썬에서 fit할 때
```python
model = LinearRegression()      # 모델 고르기
model.fit(X_train, y_train)     # 학습: 최적의 w, b 찾기
y_pred = model.predict(X_test)  # 예측: ŷ 계산
# 평가: 예측과 정답 비교
```
- 코드보다 중요한 것: **단계마다 "내가 이걸 왜 하지?"를 스스로 묻고 답할 수 있는 능력**
  - 데이터: 무엇을 예측하나? 대표성이 있나?
  - 모델: 회귀인가 분류인가? 직선으로 충분한가?
  - fit: train/test를 제대로 나눴나?
  - 평가: 베이스라인보다 나은가? 실무적으로 의미 있는가?

## 5. 성능과 경량화
- 성능: 과제를 얼마나 잘 해내는가 (벤치마크 점수)
- 경량화: 성능을 최대한 유지하며 작고 빠르고 싸게 만들기
  - 지식 증류: 큰 모델의 답을 작은 모델이 따라 배움
  - 양자화: 가중치를 덜 정밀한 숫자로 저장
  - 가지치기: 영향이 적은 가중치 제거
- 최고 성능은 따라잡기 어려워져서 경량화로 차별화 (비용, 속도, 온디바이스, 프라이버시)
- 1일차의 "효율 vs 안정성" 트레이드오프가 모델 수준에서도 나타남

## 6. 파운데이션 모델과 다운스트림 태스크
- 파운데이션 모델: 대규모 사전학습된 범용 모델. 아파트 가격 예측 같은 세부 주제에 특화되지 않음
- 다운스트림 태스크: 파운데이션 모델을 가져다 푸는 구체적 과제 (가격 예측, 문의 분류, 요약)
- 활용 방법

| 방법 | 가중치 변화 |
|---|---|
| 파인튜닝: 내 데이터로 추가 학습 | 바뀜 |
| 프롬프팅: 질문과 예시를 잘 쓰기 | 안 바뀜 |
| RAG: 내 문서를 검색해 함께 넣기 | 안 바뀜 |

- 파인튜닝도 일부 가중치만 고치는 방식(LoRA 등)을 많이 씀

## 💡 느낀 점
y = ax + b라는 중학교 수식이 머신러닝의 ŷ = w·x + b로 그대로 이어진다. 코드는 따라 칠 수 있어도, 단계마다 왜 하는지 답할 수 있어야 진짜 이해한 것이다.
